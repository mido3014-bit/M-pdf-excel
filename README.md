# تحويل جداول Bill of Material من PDF إلى Excel

أداة بايثون (سكريبت + واجهة ويب) لاستخراج جدولين فقط من رسومات PDF الإنشائية:

1. **BILL OF MATERIAL OF STRUCTURE** (الجدول الكبير: أوزان القطاعات والبراغي).
2. **STRUCTURE QUANTITY REQUIRED** (الجدول الصغير: عدد الهياكل والوزن الكلي).

وتحويلهم إلى ملف Excel واحد منظم.

## التثبيت

### 1) مكتبات بايثون
```bash
pip install -r requirements.txt
```

### 2) برامج على مستوى النظام (مطلوبة فقط لدعم OCR للملفات الممسوحة ضوئيًا)

على Ubuntu / Debian:
```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr poppler-utils
```

على Windows: نزّل ونصّب [Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki)
و [poppler for Windows](https://github.com/oschwartz10612/poppler-windows/releases)،
وأضفهم لمتغير البيئة PATH.

على macOS:
```bash
brew install tesseract poppler
```

> ملحوظة: لو الملفات كلها PDF بها طبقة نص حقيقية (مش صور) مش هتحتاج الخطوة
> دي خالص، والبرنامج هيشتغل عادي من غير OCR. الخطوة دي احتياطية فقط.

## طريقة 1: تشغيل من سطر الأوامر (لملف واحد)

```bash
python extractor.py input.pdf output.xlsx
```

## طريقة 2: واجهة ويب (لرفع أكثر من ملف دفعة واحدة)

```bash
streamlit run streamlit_app.py
```

هيفتح صفحة في المتصفح، تسحب فيها ملف أو أكثر PDF، وتظهر لك الجداول
المستخرجة مباشرة قبل التحميل، مع زرار تحميل Excel لكل ملف، وزرار
تحميل الكل كـ ZIP لو رفعت أكتر من ملف.

## دعم الملفات الممسوحة ضوئيًا (Scanned / OCR)

الأداة الآن تدعم النوعين تلقائيًا بدون أي إعداد إضافي منك:

1. **PDF بطبقة نص حقيقية** (الحالة الأكثر شيوعًا في ملفات AutoCAD/Tekla/MicroStation):
   يتم الاستخراج مباشرة من النص — الأسرع والأدق.
2. **PDF صورة ممسوحة (Scanned)**: البرنامج يكتشف تلقائيًا أن الجدول فاضي/غير
   موجود في طبقة النص، فيتحول تلقائيًا لوضع الـ OCR (`ocr_extractor.py`)
   الذي يكتشف خطوط الجدول نفسها بالصورة (باستخدام OpenCV) ثم يقرأ كل خلية
   على حدة بـ Tesseract OCR — دقة أعلى بكثير من عمل OCR على الصفحة كلها
   دفعة واحدة.

لو عايز تجبر استخدام OCR حتى لو الملف فيه طبقة نص (مثلاً لو النص موجود
لكن ملخبط أو من مصدر غير موثوق):
```bash
python extractor.py input.pdf output.xlsx --force-ocr
```
أو فعّل الخيار المقابل في واجهة الويب (Streamlit).

**قيود OCR:** الدقة في وضع OCR أقل من الاستخراج النصي المباشر، خصوصًا مع
الأرقام العشرية الصغيرة (زي 7.29 أو 0.134) — يُنصح دائمًا بمراجعة ملف
Excel الناتج يدويًا لو الملف كان OCR، ومقارنته بالرسم الأصلي.

## ملاحظات مهمة أخرى على الدقة

- الكود يحدد الجدول الصحيح تلقائيًا بالبحث عن كلمات مفتاحية مثل
  `ERECTION MARK`, `MEMBER SIZE`, `QUANTITY`, `UNIT WT` للجدول الكبير،
  و `STRUCTURE QUANTITY REQUIRED`, `STRUCTURE WT` للجدول الصغير. لو
  اختلفت هذه العبارات قليلًا في ملفاتك (مثلاً لغة أو صياغة مختلفة)
  عدّل القائمتين `BOM_HEADER_KEYWORDS` و `QTY_TABLE_KEYWORDS` في أعلى
  ملف `extractor.py`.
- في حالة اختلاف تنسيق بعض ملفاتك عن العينة المرفقة، أرسل لي عينة PDF
  حقيقية (وليس صورة) وسأضبط منطق الاستخراج عليها بدقة أكبر، لأن دقة
  استخراج الجداول من PDF تعتمد بشكل كبير على شكل الخطوط والحدود
  الفعلية داخل الملف نفسه.

## بنية الملفات

```
extractor.py        # المنطق الأساسي (استخراج من طبقة النص + تصدير Excel) + تشغيل تلقائي لـ OCR عند الحاجة
ocr_extractor.py     # منطق استخراج الجداول من الملفات الممسوحة ضوئيًا (كشف خطوط الجدول + OCR لكل خلية)
streamlit_app.py     # واجهة ويب لرفع الملفات ومعاينة/تحميل النتائج
requirements.txt     # المكتبات المطلوبة (بايثون)
```
